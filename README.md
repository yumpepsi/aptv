# APTV

หน้าเว็บดูทีวีไทยแบบ static สำหรับเบราว์เซอร์จอรถ รองรับ HLS (`.m3u8`),
responsive layout และ fullscreen โดยไม่ต้องมีระบบ build หรือฐานข้อมูล

## เปิดในเครื่อง

เปิดโฟลเดอร์นี้ด้วย VS Code แล้วใช้ส่วนขยาย Live Server หรือเปิด `index.html`
โดยตรงก็ได้ การใช้ Live Server จะใกล้เคียงกับ Hosting มากกว่า

## อัปโหลด

อัปโหลดไฟล์ต่อไปนี้ไว้ในโฟลเดอร์ `aptv` บน Hosting:

- `index.html`
- `style.css`
- `app.js`

จากนั้นเปิด `http://103.233.194.148/~trueplook/aptv/index.html`

## เปลี่ยน URL ช่อง

แก้รายการ `channels` ด้านบนของ `app.js` แต่ละช่องใส่ URL ได้หลายรายการใน
`streams` ระบบจะลอง URL ถัดไปโดยอัตโนมัติเมื่อ URL แรกเล่นไม่ได้

ควรใช้ URL แบบ HTTPS และต้องอนุญาต CORS เพราะหน้าเว็บเล่น HLS ข้ามเซิร์ฟเวอร์
ลิงก์สตรีมของสถานีอาจหมดอายุ เปลี่ยนที่อยู่ จำกัดพื้นที่ หรือจำกัด Referer ได้
ควรใช้ฟีดทางการหรือฟีดที่ได้รับอนุญาตก่อนนำขึ้นใช้งานจริง
